# Triage Labels

The engineering skills use five canonical triage roles. This table maps those
roles to the label strings used by the GitHub repository.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or coordination |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a triage role, use the corresponding GitHub label.
