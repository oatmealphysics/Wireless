3. Automated Install (Recommended)

1 Clone the repo
git clone https://github.com/oatmealphysics/Wireless.git
cd Wireless\setup
2 Run the installer
powershell -ExecutionPolicy Bypass -File .\install.ps1

This copies CLAUDE.md, settings.json, statusline.py, and all 7 custom skills to %USERPROFILE%\.claude\. Existing files are backed up with a timestamp.

3 Install marketplace plugins

Open Claude Code (claude in terminal) and run each command. See Section 5 for the full list.

4. Manual Install

If you prefer to set things up by hand instead of running the script:

4a. Create the directory

mkdir %USERPROFILE%\.claude
mkdir %USERPROFILE%\.claude\skills

4b. Copy configuration files

copy setup\claude-config\CLAUDE.md       %USERPROFILE%\.claude\CLAUDE.md
copy setup\claude-config\settings.json   %USERPROFILE%\.claude\settings.json
copy setup\claude-config\statusline.py   %USERPROFILE%\.claude\statusline.py

4c. Copy custom skills

copy setup\claude-config\skills\*.md     %USERPROFILE%\.claude\skills\

4d. Verify Python for statusline

The status bar calls python statusline.py. Verify it works:

python %USERPROFILE%\.claude\statusline.py

If your system uses python3 instead, edit settings.json and change the statusLine command:

"command": "python3 %USERPROFILE%\\.claude\\statusline.py"

5. Marketplace Plugin Install

These are installed inside a running Claude Code session. Open a terminal, run claude, then enter each command:

Marketplace Plugins

/plugin marketplace add mattpocock/skills
/plugin marketplace add Masriyan/Claude-Code-CyberSecurity-Skill
/plugin marketplace add mukul975/Anthropic-Cybersecurity-Skills
/plugin marketplace add hypnguyen1209/offensive-claude
/plugin marketplace add trailofbits/skills

NPX-installed Skills

npx skills add morluto/rea

REA (Reverse Engineer Anything) — provides 20+ binary/firmware RE tools via /reverse-engineer-anything.

Note: Each marketplace plugin prompts for confirmation. Accept the install when prompted. Some plugins fetch additional skills from GitHub on first use.

8. Verification

After completing all steps, verify the setup:

1 Open Claude Code
claude
2 Check the status bar

You should see a colored status line at the bottom showing: git branch, model name, context %, and cost.

3 Verify skills are loaded

Type / and you should see the custom skills in the autocomplete list: /ctf, /recon, /exploit-dev, /vuln-research, /msf, /reverse-engineer, /handoff.

4 Test a skill

Try asking Claude to solve a CTF challenge or run /recon on a target — the agent should use the cybersecurity identity and tool references from CLAUDE.md.

9. Platform Notes (Windows vs Ubuntu)

What's identical

  • CLAUDE.md global instructions (same file)
  • All 7 custom skills (same files)
  • All 5 marketplace plugin sources
  • Permission allowlist (130+ rules)
  • Status line script (cross-platform Python)

What differs

ItemUbuntuWindows
Python command python3 python (default Python installer)
Config path ~/.claude/ %USERPROFILE%\.claude\
Statusline command python3 ~/.claude/statusline.py python %USERPROFILE%\.claude\statusline.py
Linux-only tools Native: aircrack-ng, pspy, linpeas, strace, ltrace Use WSL2 for Linux tools, or native equivalents (x64dbg, WinDbg, WinPEAS)
WSL2 Recommendation: Many offensive security tools (aircrack-ng, Impacket, Responder, etc.) run best on Linux. Install WSL2 with Ubuntu and run Claude Code inside it for the most complete experience. The .claude/ config goes in your WSL home directory in that case.

Statusline troubleshooting

If the status line doesn't appear or shows errors:

  1. Verify Python is on PATH: python --version
  2. If you use python3 on Windows, update settings.json statusLine command accordingly
  3. The ANSI color codes work in Windows Terminal and PowerShell 7+. Legacy cmd.exe may not render them — use Windows Terminal instead.
